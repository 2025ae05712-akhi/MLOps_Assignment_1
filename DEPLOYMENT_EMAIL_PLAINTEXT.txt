Subject: MLOps Assignment 1 - Lab Deployment Instructions

Dear Team,

Please find below the complete step-by-step instructions to deploy the MLOps Assignment 1 (Heart Disease Prediction Pipeline) on your BITS Pilani lab environment.

========================================

PROJECT: MLOps Assignment 1 - Heart Disease Prediction
REPOSITORY: https://github.com/2025ae05712-akhi/MLOps_Assignment_1

========================================
QUICK START - 3 COMMANDS
========================================

COMMAND 1 - Clone Repository:
cd ~ && git clone https://github.com/2025ae05712-akhi/MLOps_Assignment_1.git && cd MLOps_Assignment_1

COMMAND 2 - Run Deployment (takes 5-10 minutes):
bash lab.sh

COMMAND 3 - Start API Service:
.venv/bin/uvicorn src.api:app --host 0.0.0.0 --port 8000

After Command 3, API will be available at:
http://localhost:8000
Swagger UI: http://localhost:8000/docs

========================================
DETAILED MANUAL STEPS (if lab.sh fails)
========================================

STEP 1 - Clone Repository:
cd ~
git clone https://github.com/2025ae05712-akhi/MLOps_Assignment_1.git
cd MLOps_Assignment_1

STEP 2 - Create Virtual Environment:
python -m venv .venv
source .venv/bin/activate

STEP 3 - Upgrade Package Manager:
pip install --upgrade pip setuptools wheel

STEP 4 - Install Dependencies:
pip install -r requirements-dev.txt

STEP 5 - Download Dataset:
python data/download_data.py

STEP 6 - Run Exploratory Data Analysis:
python -m scripts.eda

STEP 7 - Train Model with Hyperparameter Tuning:
python -m src.train

STEP 8 - Run Unit Tests:
pytest -v

STEP 9 - Start API Service:
.venv/bin/uvicorn src.api:app --host 0.0.0.0 --port 8000

STEP 10 - View MLflow Dashboard (in new terminal):
cd ~/MLOps_Assignment_1
.venv/bin/mlflow ui --backend-store-uri sqlite:///mlflow.db --port 5000

Then access at:
http://localhost:5000

========================================
TROUBLESHOOTING
========================================

Issue: bash: lab.sh: command not found
Solution: chmod +x lab.sh

Issue: Python 3.11 not found
Solution: Script uses uv to install Python 3.11. If fails, use manual steps with Python 3.10+

Issue: Port 8000 already in use
Solution: uvicorn src.api:app --port 8001

Issue: pip install fails
Solution: pip install --upgrade pip (then retry)

Issue: mlflow command not found
Solution: source .venv/bin/activate (ensure venv is activated)
